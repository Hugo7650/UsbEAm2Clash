# UsbEAm2Clash

## Description

UsbEAm2Clash uses [UsbEAm](https://github.com/dogfight360/UsbEAm)'s rule files to separate download domains for gaming platforms. Generated rules are available as Clash YAML, sing-box JSON, Mihomo MRS, and sing-box SRS files.

Each link group contains the repository file, the GitHub Raw URL, and the jsDelivr URL.
